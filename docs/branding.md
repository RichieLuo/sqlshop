# Shop 图标与 Windows 标题栏

三个应用保留各自的动物形象和品牌色，原始 PNG 不做破坏性修改。Windows 标题栏和系统图标采用以下共同规范。

## 原生图标

`src/branding_icon.rs::icon_image()` 是唯一的图标像素入口，`build.rs` 的多尺寸 ICO 和 `branding.rs::icon_data()` 均调用它，避免运行中的任务栏图标与 EXE 图标不同。

- 画布为 1024×1024。Windows 的圆角实心底板填满画布，去掉原先四周各 10% 的透明留白，可见边长增大约 25%；macOS/Linux 保留 80% 底板和各 10% 的透明边距。
- 源图按 alpha ≥ 8 的可见边界裁去留白，排除导出时极淡的杂点；保持宽高比，居中缩放。
- Windows 下，已带底板的 LinkShop/RPShop 图像按 1024px 上限嵌入，透明的 SQLShop 猞猁主体按 920px 上限嵌入，主体和底板同步放大；macOS/Linux 仍分别使用 820px、736px。
- 共同的圆角遮罩覆盖最终画布，三者的可见外框一致。底板维持实心，不因源图的圆角或透明背景产生缺口。
- ICO 继续包含 16、24、32、48、64、128、256px 七档。回归测试逐档核对 alpha 实心边界与透明四角，而非只比较 PNG 的像素尺寸。

标题栏纹理通过 `branding::title_texture()` 从同一份图标数据加载并缓存，绘制时使用固定的 28×28 逻辑像素框。

## Windows 标题栏

以 SQLShop 为参考，LinkShop/RPShop 在 Windows 下隐藏原生装饰，使用单层应用标题栏。品牌区宽 160px、高 34px，左侧内距 16px，28px 图标后留 8px，再显示 18px 加粗产品名。浅色背景为 RGB(238,238,238)，深色背景为 RGB(21,28,35)。

右侧提供贴边的最小化、最大化/还原和关闭按钮，支持拖动与双击最大化/还原；Windows 11 的 DWM 圆角及窗口边框与 SQLShop 一致。工程名、保存状态、预览、导出、本地工作区等业务操作继续保留。关闭按钮沿用应用原有的忙碌与未保存内容保护。

macOS/Linux 的标题栏布局和图标外边距保留各项目原有行为。

## 本机验证

在 PowerShell 中运行 `scripts/dev.ps1 verify` 检查格式、lint 与默认测试，使用 `scripts/package.ps1` 生成包含最新图标和标题栏的程序。设置 `SHOP_ICON_PREVIEW` 后运行 branding 的图标测试，可把真实渲染结果写入指定 PNG，便于对比；预览输出放在 target 目录。

Windows 图标尺寸修复包输出到 `dist/icon-size-20261026/`，与之前的包分开保留。安装后，开始菜单和文件关联使用新 EXE 的图标；重新启动应用后，任务栏与标题栏使用同一套放大后的图标。
